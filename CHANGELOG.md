# Changelog

## 4.5 public edition

- Publish seven technical/source methods: conversion, bibliographic acquisition, scientific reading, PDF annotation recovery, literature survey, graph retrieval and semantic retrieval.
- Publish the 4.5 orchestration source with explicit configuration and external dependency requirements.
- Exclude personal workflows and related editorial, voice, administrative and teaching categories, including their skills, templates, examples and records.
- Document the narrower catalog and migration boundary.
- Document the earlier release generations and the distinction between source availability and verified operation.

This entry describes the public package. It makes no claim that a fresh deployment has passed live workflow acceptance. See [features and limits](docs/features-and-limits.md).
