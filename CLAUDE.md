# Public Praxis operating rules

This repository is the sanitized public projection. Follow the user's task and the active host's capabilities. Shared behavior belongs in the skill procedure; provider-specific behavior belongs in adapters.

- Keep private knowledge, identifiers, accounts, credentials and operational records outside this repository.
- Read `docs/publishing-policy.md` before adding projected material.
- Preserve source provenance and report missing evidence. A passing test does not establish live qualification or delivery.
- Keep the skill catalog and setup documentation synchronized with behavior changes.
- Use temporary directories and invented identities for tests. Do not connect private production data for a routine test.
- Preserve user work and unrelated changes. Do not install, publish, send messages or change schedules unless the task authorizes that action.
- Carry authorized work through verification. Ask only when a consequential decision remains unresolved; a new workflow step does not reset existing authorization.

The canonical projection source owns generated skill text. Reconcile public changes there so regeneration does not discard them.
