# Migration to the restricted public catalog

This edition publishes seven technical/source methods alongside the generic runner integration. Personal workflows and related editorial, voice, administrative and teaching skills are excluded as complete categories. Earlier source snapshots receive the same review; identifier substitution alone is insufficient.

Before upgrading an existing installation, inventory its current skills and preserve locally authored work. Installing the public catalog does not delete older discovery copies. Remove excluded or obsolete local copies deliberately if that is the intended migration; do not mistake their continuing presence for inclusion in this release.

Claude Code and Codex consume the same procedure. Verify the installed auxiliary files and the active host's actual tools. A host UI and a coordination/execution adapter are different components.

For runner work, supply valid agent contracts, compatible host and pinned engine dependencies. The public projection does not carry private registries, decisions, execution history or another machine's install state. Read [architecture](architecture.md) and [configuration](configuration.md) before connecting a deployment.
