# Codex adapter

Read the sibling `CLAUDE.md` as the shared operating manual. Use only capabilities exposed by the active Codex host.

Codex discovers skills in `~/.agents/skills/`. It does not run Claude hooks, slash-command registration or transcript machinery. Do not claim those ran in a Codex session. Verify effects from resulting files and tool output.

Native host workers are not configured institutional roles. Preserve explicit role, provider and model routing contracts when a task invokes them.
